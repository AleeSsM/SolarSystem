# Manual de usuario

## Vista general

La aplicación muestra un Sistema Solar 3D a pantalla completa. Los controles principales están en la barra superior, la columna izquierda (Cámara, Tiempo) y el panel **Info** a la derecha.

## Barra superior

| Control | Función |
|---------|---------|
| **Tour guiado** | Inicia un recorrido automático de 12 paradas |
| **Movimiento helicoidal** | Activa estelas helicoidales en el movimiento |
| **Código fuente** | Enlace al repositorio en GitHub |

Durante el tour aparecen **Anterior**, **Siguiente** y **Salir** en la misma barra.

## Cámara (panel izquierdo)

- **Vista sistema** — vista general del sistema
- **Modo libre** — orbitar y hacer zoom con el ratón
- **Viajar a** — selecciona un planeta para seguirlo
- **Zoom** — visible al seguir un planeta

Arrastrar rota la vista; la rueda del ratón hace zoom.

## Tiempo (panel izquierdo)

| Control | Función |
|---------|---------|
| Play / Pausa | Reanuda o congela las órbitas |
| Tiempo Real | Ancla posiciones a la fecha actual |
| x1 … x1000M | Multiplicadores de velocidad |
| Brillo planetas | Aclara la cara no iluminada |
| Orbitas / Etiquetas | Toggles de visualización |

A x1 el movimiento es casi imperceptible; use x100k o x1M para apreciar las órbitas.

## Panel Info (derecha)

Pestañas **Planeta**, **Sistema Solar**, **Detalles** y **Física**. Click en un planeta para ver su ficha.

Use **−** en cualquier panel para ocultarlo; la pestaña correspondiente permite reabrirlo.

## Planetas

- Click en un planeta → viaje cinematográfico y ficha en Info
- Luna orbitando la Tierra; Io orbitando Júpiter
- Cinturón de asteroides entre Marte y Júpiter

## Escala

La simulación no es a escala real. Distancias y tamaños están ajustados para legibilidad; los periodos orbitales sí son reales. Consulte la pestaña **Detalles** o `docs/escalas.md`.
